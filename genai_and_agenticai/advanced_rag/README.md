# Advanced RAG

This section focuses on advanced techniques that improve the standard Retrieval-Augmented Generation (RAG) workflow.

## Why This Matters
Traditional RAG is useful, but it can still struggle with:
1. Evaluating the quality of retrieved information
2. Correcting its own mistakes
3. Improving response reliability in complex queries

To address these limitations, we explore advanced approaches that add self-checking, reflection, and correction mechanisms.

## Types of Advanced Approaches
In this folder, we will learn about two important advancements:
1. Corrective RAG
2. Self-RAG

## What You Will Learn
By exploring these examples, you will understand how these methods improve retrieval quality and make generated answers more trustworthy.

## Folder Structure
The content is organized into the following folders:
- [corrective_rag](corrective_rag/README.md) - Examples and notes for Corrective RAG
- [self_rag](self_rag/README.md) - Examples and notes for Self-RAG
